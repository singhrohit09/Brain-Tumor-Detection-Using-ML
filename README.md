# Brain Tumor Detection Using Machine Learning

## Overview
This project uses a trained deep learning model to detect brain tumors from MRI images.

## Features
- MRI Image Upload
- AI-Based Tumor Detection
- Confidence Score Prediction
- Flask Web Application
- User Friendly Interface

## Technologies Used
- Python
- TensorFlow
- Flask
- HTML
- CSS
- NumPy
- Pillow

## Tumor Classes
- Glioma
- Meningioma
- Pituitary
- No Tumor

## How to Run

```bash
pip install flask tensorflow pillow numpy
python app.py
